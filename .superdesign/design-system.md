# Alba · Tramonto design system

Tramonto is a private Italian notebook workspace beside Alba. Preserve its sage, warm ivory and apricot identity, with editorial serif titles and simple system-sans controls. The product should feel like a quiet, capable study desk. UI copy is Italian.

## Palette and typography
Light: background #f4f5ee, paper #fffef9, soft surface #edf1e7, ink #263c31, secondary ink #788275, border #e4e8dc, primary sage #456b43, apricot #d58c57 / #cc8554. Dark: background #111c18, paper #192820, soft surface #23362a, ink #e2eadd, secondary #9aa99a, border #2d3f31, primary #aed087. Georgia for wordmark and page titles; system sans for navigation/forms; monospace only in code and technical consoles. Existing sunset ◒ plus tramonto. wordmark is the Tramonto identity. Avoid adding a new logo, stock photos or a mascot.

## Workspace hierarchy
One compact header: portal switch, saved status and necessary global actions. A quiet sidebar contains notebooks, searchable pages and new-page action. The primary surface is a real A4 notebook page on an understated canvas. Note title is distinct from body content. Group text formatting in one toolbar; place font/paper settings together. Secondary tools open a coherent tool panel with previews and one clear “Inserisci nel quaderno” action. Objects inserted into the page expose contextual move, width/scale, alignment/wrapping and delete controls. Keep tool settings and output out of the writing area until insertion.

## Notebook behavior and print
Paper lines are a subtle page background tied to a stable 28px text baseline; headings use sensible multiples without overlapping lines. Text editing preserves the insertion cursor when toolbar actions are used. Formulas, graphs, drawings, circuits and images become visible notebook objects through an explicit insertion action. Selection makes an object’s controls discoverable. Printer output contains notebook content with consistent A4 margins, page breaks, visible diagrams and reliable title placement; editor chrome is hidden.

## Geometry and access
Desktop sidebar about 250–275px, content centered; A4 aspect 210:297. Spacing built around 8/12/16/24/32px; controls 36–40px high with 44px touch targets on mobile, clear 12–14px labels. Border 1px; radius 8–12px controls and 16px panels; gentle shadows only on elevated layers and paper. Use one dominant sage action per area, apricot sparingly. Sidebar becomes a drawer or compact notebook switch on narrow screens, formatting can wrap or scroll, and page fits width without horizontally overflowing the viewport.

Use native semantic buttons/labels, visible focus, status announcements, contrast-aware text and accessible tab/selection state. Respect reduced motion. A save failure must stay clearly visible without covering the writing surface. Keep private-data and server implementation explanations in appropriate settings/help rather than dominant workspace UI.
