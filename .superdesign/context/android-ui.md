# Native Android UI source and actual render branch

The requested target is the installed Java Android app, package local.alba. This is independent of the web pages; this change concerns native Views only.

MainActivity.java provides shell(), menu(), navigate(), chatView(), renderChat(), notebooks(), editor(), settings(), and Notte panels. There are no custom local layout imports. UI dependencies are NotebookCanvas (ink), NativeMarkdown (chat text/tables), and NativeBars (Test Lab charts). NativeApi and SessionStore are transport/storage only. AndroidManifest.xml uses AlbaTheme, with themed native controls and light/dark variants. Layout is Java, without XML layouts, React, CSS, or WebView.

Current mobile palette from NativeUi: BG #101b16, PANEL #1b2a21, INK #ecf0e7, SAGE #b2ce9a; light #f4f5ee / #fffef9 / #243b2c / #476844. Native text controls use system sans; header uses serif. No logo image is currently rendered in the header; the application launcher icon is Albi, outside the screen render. Do not add an invented logo or web-only mark.

Baseline before approved redesign: root vertical LinearLayout with system/IME inset padding. First a header with 28sp serif current section title (weight=1), default Android Menu dropdown button, then a separate 12sp status line, then body with remaining height. PopupMenu has 13 ungrouped section rows (admin), only Alba and settings for regular users. No bottom navigation.

Baseline chat: ScrollView weighted to remaining height, 12dp feed padding; rectangular full-width user/assistant bubbles with 11sp author and native Markdown. Separate streaming partial text. Bottom composer is 94dp tall plus margins; Send and Stop stack in a second column. Three distinct channel drafts persist independently.

Baseline Tramonto editor branch: the whole body is a vertical ScrollView. 15sp title EditText first, then text EditText minimum 10 lines, then a Save/Export/Pages row, then Drawing title, then a 270dp-high paper canvas, then undo button. Advanced formula/circuit previews follow. Canonical canvas coordinates are 1000x640. Touch drawing captures parent scroll interception; canvas must remain usable with fingers/stylus. Saving preserves all structured page fields and uses version checks. A user currently needs to scroll past a large text field to reach drawing.

Main sections: Alba chat; Tramonto notebook list and note editor; Notte chat, memory/connectors, learning diary, activity, personal model, token statistics, emotions/system, Test Lab, project/evolution; settings. Administrator gates remain. IT and EN labels are supported. Do not remove Notte tools; group them behind an understandable More menu. No external-browser flow for primary features.

Requested redesign: modern, compact native phone navigation and room to read/draw. Suggested direction to evaluate: 48dp header with short portal wordmark and More icon, quiet one-line connection/save status, 56dp bottom navigation Alba / Tramonto / Notte; contextual note tabs Text / Draw, large canvas taking available height in Draw, single compact drawing toolbar, settings and extra Notte tools in a grouped sheet only when opened. Use real labels with icons and 44-48dp touch targets. Menu must dismiss before returning to work. Drawing mode hides the text editor and global bottom navigation when an explicit focus toggle is active; retain a clear Back/Done action. A narrower composer with one Send button frees chat height; Stop only while a response is active. Palette may be softly refined while preserving sage/apricot identity.

New Tramonto content fields already being delivered separately: font_size 8..72 px and letter_spacing -2..6 px; font editor includes 411 symbols, supports 512 glyphs, compact glyph side bearings. Native note editing should honor and preserve these style values.
